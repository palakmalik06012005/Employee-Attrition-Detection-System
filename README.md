Predict which employees are at risk of leaving your organization using **Machine Learning**!  
This project uses a **Random Forest Classifier** to help HR teams make **data-driven retention decisions** and understand **key factors influencing attrition**.  

---

## 📊 Why This Project?

Employee attrition is costly 😓—losing experienced staff affects productivity and morale.  
This system empowers HR professionals to **identify at-risk employees**, **analyze key predictors**, and **take proactive measures** to retain talent.  

**Highlights:**  
- 🔢 Binary and One-Hot Encoding for categorical features  
- 🌲 Random Forest Classifier for accurate predictions  
- 📈 Streamlit app for interactive exploration  
- 🎯 Easy-to-read insights for HR decision-making

## 📂 Dataset

The dataset includes:  

- Demographics (Age, Gender, etc.)  
- Job-related factors (Department, JobRole, OverTime, etc.)  
- Performance & satisfaction metrics  
- Attrition (Yes/No)  

---

## 📈 Model

- **Algorithm:** Random Forest Classifier  
- **Evaluation Metrics:** Accuracy, Precision, Recall  
- **Purpose:** Predict the probability of employee attrition
